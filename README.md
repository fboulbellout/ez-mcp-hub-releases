# ez-mcp-hub-releases
Installers and auto-updates for EZ-MCP Hub: one place to see, switch on/off and set up the MCP servers of all your AI tools. Mac (notarized) &amp; Windows. 


# EZ-MCP Hub – releases

Download the latest version from **[Releases](../../releases/latest)**:

| Computer | File |
| --- | --- |
| Mac (Apple Silicon & Intel) | `EZ-MCP Hub-<version>-universal.dmg` – signed and notarized by Apple |
| Windows (x64) | `EZ-MCP Hub Setup <version>.exe` – first start: More info → Run anyway |

Once installed, EZ-MCP Hub checks this page for new versions and offers to update itself.

This repository holds installers only; the source code is kept elsewhere.
